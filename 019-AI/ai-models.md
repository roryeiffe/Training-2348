## Image Generation

**DALLE**

* OpenAI model for text → image generation
* Good at creative, artistic, and realistic imagery
* Supports inpainting/outpainting for edits
  - Editing existing content
  - Expanding beyond the pictures borders
* Strong prompt understanding with natural language

**Imagen**

* Google image generator using diffusion models
* Emphasizes photorealism and visual coherence
* Uses large language model for prompt encoding
* Strong at typography and fine details

**Firefly**

* Adobe’s AI image suite integrated with Creative Cloud
* Designed for commercial-safe content (licensed data)
* Supports generative fill, recolor, and style transfer
* Focused on design workflows

## Vision

**CLIP**

* Connects images and text in shared embedding space
* Enables zero-shot image classification
* Used for image search and moderation
* Foundation for many multimodal systems

**Google Vision Transformer (ViT)**

* Transformer-based alternative to CNNs
  * CNN - Convolutional Neural Network
* Strong performance on image classification
* Scales well with large datasets
* Backbone for many Google vision tasks


## Text to Speech

**OpenAI TTS**

* Neural, natural-sounding speech synthesis
* Multiple voices and styles
* Good emotional and prosody control

**Amazon Polly**

* Cloud TTS with many languages/voices
* SSML support for fine control
* Real-time streaming option

**OpenAI Whisper**

* Speech → text (ASR), not generation
* Highly accurate transcription
* Multilingual + translation support
