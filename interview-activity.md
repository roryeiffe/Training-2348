# Interview Activity
- Trios
  - For 20 minutes, Person A will ask Person B questions
  - Next 20 minutes, Person B will ask Person C questions
  - Next 20 minutes, Person C will ask Person A questions
- Whoever is not interviewing can observe
- Keep an eye out for soft/technical skills
- Can use questions from [Here](./900-practice-questions/) or look up your own

## Insights Gained
- Adding a summary to sum up and indicate that you're done speaking.
- Be mindful that some interviews have more than one interviewer
- Practice a 60-second pitch, in case asked about yourself
- Practice Behavioral Questions
  - https://levelup.gitconnected.com/a-complete-student-guide-to-software-engineering-behavioral-interviews-6ebb2264f5f6
- Referring to code in projects and in class
- Speaking too fast/slow
- Interviewers can pick up in you're not sure, might give hints
