## Chrome DevTools
- As we saw in Chrome, we can make use of certain tools in our development
- To open up the tools, we can right-click and click "inspect element"

### Elements
- Lets us view the elements on the page, inspect their styles
- Useful for identifying pieces of the box model

### Console
- View the output from any console.logs in our code
- Will be used to debug any projects we load in our browser (HTML with script, React)

### Sources
- View the source code for what is being run in the browser
- Can set breakpoints

### Network
- Shows network requests
  - API calls
  - Loading Assets
- Switch to network tab and then do something on the page that triggers some network operation/call, then we will see those appear in the list
  - ex: refresh the page
  - or if we click a button that makes an API call

### Performance
- Helps to analyze runtime performance
  - rendering, scripting
