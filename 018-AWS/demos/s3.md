## S3 
- Navigate to S3 console on AWS
- Create a bucket
  - Specify a name, must be globally unique
  - Enable ACLs
  - Uncheck the block public access option
    - Acknowledge the fact that this means our objects can be made public
  - Once the settings are configured, "Create Bucket"
  - Navigate to the bucket and upload objects
- Upload different objects
  - On the bucket page, we click "upload"
  - We can upload files individually or an entire folder

## Static Front-End hosting
- First, ensure we have an html file uploaded to S3 bucket and allow read access
  - Click on Object
  - Go to Permissions tab
  - Edit ACL settings and ensure "Read" options are checked
- From the bucket menu go to properties and scroll to the bottom
  - Click "Edit" next to the Static Website Hosting section
  - Enable
  - Enter the name/path of the html file that we uploaded
- If you want to host a more complex app like a React app or Angular, we first need to build the app into   
  - https://docs.aws.amazon.com/prescriptive-guidance/latest/patterns/deploy-a-react-based-single-page-application-to-amazon-s3-and-cloudfront.html

## Deleting the Bucket
- First, empty the bucket by deleting all objects
  - Can do this from the bucket menu, checking the box/circle next to the item and clicking delete
- Once all objects are deleted, we can delete the bucket from the list of buckets by checking the circle next to the bucket name, clicking delete, and filling out the prompt
